# 电路板设计工作台（第一版）

板框、焊盘、铜线（折线）、过孔与网络声明的编辑；人工走线可保存、撤销/重做；
后端按真实几何计算连通、短路与细小间隙。

## 运行

```bash
# 后端（默认 :8080，板子 JSON 落盘到 ./data，重启不丢失）
cd backend
go run ./cmd/server -addr :8080 -data data

# 前端（已通过 Vite 代理把 /api 转发到 :8080）
cd frontend
npm run dev
```

## 编辑操作

- 选择/平移：点选焊盘、导线或过孔；拖拽空白平移；滚轮以光标为锚点缩放。
- 放置焊盘：在当前工作层放置圆形焊盘（可带孔），可在侧栏填写声明网络。
- 手工连线：逐点单击折线节点，右键或回车完成，Esc 取消；线宽与层在侧栏选择。
- 放置过孔：在选中过孔的侧栏中勾选它声明连接的层。
- 保存后自动跑 DRC；撤销/重做同时覆盖「未保存的本地编辑」和「已保存版本」。
- 导出为完整板子 JSON；导入时默认保留全部 ID，勾选「覆盖同 ID」可替换同名板。

## 几何与电气规则（后端 `internal/geom`、`internal/drc`）

所有坐标单位为毫米，判定只使用模型几何；界面缩放只改变毫米到像素的
显示系数，不参与任何连通/间隙判断。

- 焊盘-导线：导线走廊（中心线 ± 线宽/2）与同层焊盘圆盘相交才算接触；
  环形焊盘落在孔内的点不算铜。
- 导线-导线：仅同一层、中心线距离 ≤ (w1+w2)/2 才接触。
  不同层导线几何上交叉不产生任何连接，也不触发短路/间隙错误。
- 过孔：只与它 `layers` 中声明的层上的导线/焊盘连接；未声明的层即使
  几何重叠也绝缘。至少需要两个不同层才构成跨层连接。
- 连通性：用并查集在上述真实接触关系上合并节点；网络名称相同但没有
  铜接触会报 `net-open`，绝不会因为名字相同就视为接通。
- 短路：任意接触连接了两个不同声明网络时报 `short`，错误带具体接触
  坐标、层和两个元件 ID。
- 细小间隙：同层不同网络导线边缘间距大于 0 但小于最小间隙时报
  `clearance`，位置取最近点中点；已经接触的走短路规则。

API：

- `GET/POST /api/boards`，`GET/PUT /api/boards/{id}`
- `POST /api/boards/{id}/undo|redo|drc|import`
